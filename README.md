# 🧭 App Turismo

Aplicativo de turismo desenvolvido em **Flutter**, com foco na navegação entre páginas, exibição de locais turísticos e gerenciamento de sessões com login, durante a matéria de Desenvolvimento Mobile.

## 📱 Visão Geral

Este projeto foi criado com o objetivo de praticar conceitos de desenvolvimento mobile utilizando Flutter. O app simula um sistema de turismo, com diversas rotas, telas de apresentação, login e perfil.

## ✨ Funcionalidades

- Tela de login
- Menu principal com navegação
- Páginas de apresentação
- Tela de perfil
- Página com lista de lugares turísticos
- Página de mensagens

## 🔧 Tecnologias Utilizadas

- Flutter SDK
- Dart
- Material Design
- Navegação com `routes`
- Suporte multiplataforma

## 🚀 Como Executar

Certifique-se de ter o Flutter instalado. Depois, execute os comandos:

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/app_turismo.git

# Acesse o diretório
cd app_turismo

# Instale as dependências
flutter pub get

# Rode o app
flutter run
```
